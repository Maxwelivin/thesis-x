HOW TO
  • 輕點任務：未開始 → 進行中 → 完成
  • 任務往右滑：直接完成；往左滑：重置
  • 面板往下拉或點背景：關閉
  • 面板右上角 ✎：編輯標題、新增／刪除／排序任務、標記 ★ 關鍵
  • 面板右上角 🎓：和萊特博士討論，拆分任務、找關鍵任務

INSTALL

iPhone：用 Safari 開啟 → 分享 → 加入主畫面

Android：用 Chrome 開啟 → 選單 ⋮ → 安裝應用程式

iPhone 上，Safari 和主畫面 App 的資料是分開的；加入主畫面後請在 App 裡匯入資料。
